# tasqueo-legal

Páginas públicas do Tasqueo: política de privacidade e termos de utilização (português e inglês).

- `privacy.html`: Política de Privacidade
- `terms.html`: Termos de Utilização
- `index.html`: página inicial

Publicadas com o GitHub Pages. Os endereços estão no `Info.plist` da app (`DitaPrivacyPolicyURL` e `DitaTermsURL`).
